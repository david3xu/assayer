# Provenance

## Source data (CC BY 4.0)

The files under `data/` (`data/sources/*` and `data/calibration/*`) are NVCL WA
source data. Each `*-scalars.csv` is accompanied by a `*-source.json` manifest
recording `licence: CC-BY-4.0`. The data is used under CC BY 4.0 with the
attribution recorded in every manifest, verbatim:

> Geological Survey of Western Australia, National Virtual Core Library (NVCL) WA node, via AuScope. Licensed CC BY 4.0.

## Synthetic output (CC0 1.0)

Only synthetic output produced by Assayer is dedicated to the public domain
under CC0 1.0, as stated in `LICENSE`. The CC BY 4.0 source data itself is not
relicensed. Provenance and attribution for the fitted source are retained in
every run manifest regardless.
